# 🐍 Fundamentos de Python para Ciencia de Datos

Ejercicios de estadística y procesamiento de datos **escritos desde cero, sin librerías**: suma, promedio, mínimos, máximos, frecuencias e histogramas implementados a mano.

Proyecto académico de Ciencia de Datos — Ingeniería en Informática, UTEM.

## Ejercicios

| Archivo | Contenido |
|---|---|
| `ejercicio1.py` | Funciones estadísticas propias (suma, largo, promedio, mínimo, máximo) con validación de datos no numéricos; conversión de temperaturas y análisis por ciudad |
| `ejercicio 2.py` | Reporte de notas por estudiante: promedio, clasificación (Reprobado / Suficiente / Aprobado / Destacado), conteo, filtrado, ordenamiento y búsqueda |
| `ejercicio3.py` | Frecuencias y moda, histograma en texto, clasificación por tramos, análisis de texto (frecuencia de palabras, top N, diversidad léxica) y bigramas |

## Cómo ejecutarlo

Solo necesitas Python 3, sin dependencias:

```bash
python ejercicio1.py
python "ejercicio 2.py"
python ejercicio3.py
```
